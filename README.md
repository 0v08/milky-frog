# 奶蛙远征 · 卡牌肉鸽

一个对标《杀戮尖塔》的竖屏 H5 卡牌肉鸽，双击 `index.html` 就能玩。美术全部来自原版《勇者奶蛙传》。

## 怎么玩

- 直接双击 `index.html`（手机用局域网/静态服务器打开也行，`python -m http.server` 即可）。
- 每回合 3 点能量（拿到「能量核心」遗物变 4 点），手牌 5 张，点卡牌打出，点「结束回合」让敌人行动。
- 战斗胜利后从三张牌里选一张加入卡组，不想要可以跳过。
- 9 层地图：战斗、精英、商店、篝火、随机事件，最后是第 9 层的 Boss。

## 四大流派（核心机制）

打完**第 2 层**会弹出「流派觉醒」页，从四条路里选一条，选完会送一件流派核心遗物，卡牌奖励池也会开始按流派倾斜（每轮必出一到两张本流派牌）。

觉醒页会给流派打「共鸣」标记——那是你当前的战斗数据达标了（见下表），有共鸣说明这条路本来就适合你这局的打法，但没有共鸣也能选。

| 流派 | 核心遗物 | 打法 | 共鸣条件 |
| --- | --- | --- | --- |
| ♾️ 无限抽牌 | 无限蛙壶：每回合额外抽 4 张 | 牌抽得多就打得凶，靠「心流 / 循环 / 连环」把每次抽牌换成伤害，一回合能摸十几张打空牌库 | 累计抽牌 ≥ 40 |
| 🩸 卖血叠伤 | 血契石：开战回 6 血；每掉 1 点血叠 2 伤害；半血以下每回合再 +3 力量 | 自己扣血换伤害，血越少越猛，靠「血祭 / 献祭 / 嗜血」主动卖血叠力量 | 累计掉血 ≥ 20 |
| 🛡️ 无限格挡 | 铁壁甲：回合结束保留 50% 格挡 | 格挡不清零，越滚越厚；「盾舞 / 盾反 / 铁壁架势」把格挡当伤害打出去 | 累计获得格挡 ≥ 80 |
| ☠️ 剧毒蔓延 | 剧毒瓶：每回合开始给敌人叠 2 层中毒 | 中毒每个敌方回合结算一次、之后衰减 2 层，上限 25 层；「催化 / 毒爆 / 腐蚀」负责叠高再引爆 | 累计中毒 ≥ 20 |

每条流派 6 张专属牌，共 24 张（部分带「消耗」，一局只能用一次）。

## 常驻状态栏

顶部一条常驻 HUD：左边金币，中间流派标记，右边已获得的遗物（图标 + 名字，多了可以横滑）。

- 点任意遗物 → 弹出详情卡（图标、名称、效果），点遮罩或「知道了」关闭。
- 地图、战斗、商店、篝火、事件、奖励、卡组、删牌界面都有；标题页和结算页不显示。

## Boss 与二阶段

Boss 从 4 个里随机：憋笑魔王、队长、将军、元帅。血量打到 **50% 以下会进二阶段**：换一张立绘、攻击模式变狠、额外加力量，名字旁出现「第二阶段」徽章，屏幕上方也会弹提示。

## 内容量

- **49 张卡**：25 张通用（打击、防御、蛙跃、重击、连击、毒牙、回旋踢、撞击、铁壁、闪避、毒雾、凝神、奶昔、蓄力、荆棘、处决、勇者咆哮、护盾发生器、再生、憋笑、蛙跳斩、汲取、盾击、蛙神祝福、狂暴）+ 24 张流派牌。
- **12 件遗物**：勇气徽章、蛙之泪、磨刀石、盾牌碎片、抽牌袋、能量核心、毒囊、奶蛙之心 + 四件流派核心。
- **敌人 10 种**（普通 8 + 精英 2），血量与伤害随层数缩放：
  - 前期（1–4 层）：企鹅兵、木箱怪、宫廷小丑、看门猎犬
  - 后期（5–9 层）：城堡盾卫、书记官、炸弹兵、追兵
  - 精英：重锤兵、暴走企鹅
- **Boss 4 种**：憋笑魔王、队长、将军、元帅（都可二阶段）。
- **7 段场景背景**：村庄 → 森林 → 雪山 → 大桥 → 城堡庭院 → 大厅 → 王座间，按层数递进。
- **4 个随机事件**：三眼商人、蛙之泉、赌徒青蛙、古老石碑。

## 双端适配

一套代码，按屏幕断点自动换布局：

| 屏幕 | 布局 |
| --- | --- |
| 手机竖屏（≤640px 宽） | 单列满屏，卡片横向滑动，底部固定「结束回合」；适配刘海屏 safe-area 和 100dvh（地址栏收起不会跳动） |
| 小平板 / 大手机（≥640px） | 居中「游戏机」面板：圆角 + 阴影，四周用封面插画虚化做背景，字号和卡牌整体放大 |
| 桌面（≥900px） | 面板拉到 1060px，**战斗改为左右两栏**：左边舞台（敌人立绘 + 血量 + 意图），右边操作区（状态 + 手牌 3 列网格 + 结束回合），一屏能同时看到 9 张手牌 |
| 手机横屏 / 矮窗口（高 ≤560px） | 同样左右两栏，手牌变单行横向滑动，避免竖向不够用 |

断点全部集中在 `index.html` 末尾的四段 `@media`（640 / 900 / `max-height:560` / 超小屏），改布局只动这几块。战斗界面的两栏靠 `.bwrap > .bleft + .bright` 两个容器切换方向，竖屏是 `flex-direction:column`，宽屏改成 `row`，DOM 不用重建。

触摸侧做了 `-webkit-tap-highlight-color:transparent`、`user-select:none`、`overscroll-behavior:none`，不会出现长按选中和页面回弹；鼠标侧按钮有 `:active` 缩放反馈。

## 技术实现

单文件 HTML + 内联 CSS/JS，外部资源只有本地 `art/` 图片，断网也能玩。

改数值搜 `CARDS`、`RELICS`、`PATHS`、`POOL_A` / `POOL_B` / `POOL_ELITE` / `POOL_BOSS`，缩放系数在 `startBattle()` 里；二阶段在 `checkPhase()` 里；改背景顺序搜 `FLOOR_BG`。

## 自测

- `?selftest`：随机策略跑 150 局（第 2 层后随机选流派），结果 JSON 打到页面上。
- `?selftest=smart`：贪心策略（会优先补格挡、叠 buff）。
- `?selftest=paths`：四条流派各跑 150 局，输出 `byPath` 明细。
- `?selftest=paths&smart`：四条流派各 150 局 + 贪心策略。

两个 bot 的通关率（每格 150 局）：

| 流派 | 随便乱打 | 优先防守 |
| --- | --- | --- |
| ♾️ 无限抽牌 | 17% | 24% |
| 🩸 卖血叠伤 | 33% | 25% |
| 🛡️ 无限格挡 | 35% | 21% |
| ☠️ 剧毒蔓延 | 42% | 13% |

两种打法互有胜负，说明牌组不是靠单一数值通吃：毒流对「无脑铺牌」最友好、对谨慎打法最吃亏；格挡流正相反，需要规划格挡保留和盾反时机。真人玩通常落在两列之间。调整数值时建议两列都跑一遍，别只看一列。

## 本地存档

进度自动存在浏览器 `localStorage`，不需要登录、不上传任何数据。

- 每次进入新节点、开打、买牌、选流派、回到地图时自动写档
- 关掉页面、关掉浏览器、重启电脑，再打开还是同样的进度：标题页会出现「继续远征 · 第 N / 9 层」
- 战斗打到一半刷新也能接上（血量、手牌、能量、抽牌堆都在）
- 通关或战败会自动清档，并在标题页累计「挑战 X 次 · 通关 Y 次 · 最深 Z 层」
- 换浏览器、无痕窗口、清理浏览器数据会丢档

存档键名：`milkyfrog.save.v1`（进度）、`milkyfrog.stats.v1`（战绩）。想手动备份，控制台执行 `copy(localStorage.getItem('milkyfrog.save.v1'))`。

## 分享给别人玩

游戏是纯静态的，`index.html` + `art/` 放到任意静态托管即可：

1. **同一个 WiFi 立刻玩**：双击 `启动服务器.bat`（或 `node serve.js`），按打印出来的局域网地址用手机打开
2. **GitHub Pages**：建仓库 → 上传 → Settings → Pages
3. **Netlify Drop**：<https://app.netlify.com/drop> 拖文件夹，几秒出网址

详细步骤见 `部署说明.md`。打包好的 `奶蛙远征-web.zip`（2.6 MB）可直接拖去部署。
